New Rust Libraries in work:

- openai-utils: a rust library for using openai/chatgpt api
- claude-utils: a rust library for using anthropic/claude api
- google-genai-utils: a rust library for using google cloud language models
- workclerk: a memory management library for large language model for those whom want to run an endless chat session with perpetual memory, this library will work together with LLM services (like openai, anthropic, gemini), or self hosted models (additional setup required)
